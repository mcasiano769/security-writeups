# Linux Fundamentals Part 1 — TryHackMe

**Difficulty:** Easy
**Category:** Linux Fundamentals
**Date completed:** 2026-09-02

## Summary
Introductory room covering the basics of navigating a Linux filesystem from the terminal, plus using `grep` to search file contents. First hands-on room completed as part of Security+ study.

## What I Did
- Practiced core navigation and file management commands: `ls`, `mkdir`, `cd ..` (and general directory traversal).
- Used `grep` to search inside a text file for a specific string, which located a flag hidden in the file content.

## What I Learned
- Basic filesystem navigation is fast once the core commands are muscle memory — `ls` to see where you are, `cd` to move, `mkdir` to build structure.
- `grep` is the go-to tool for searching file contents rather than opening and scanning files manually — useful well beyond this room (log triage, hunting for strings in output, etc.).

## Tools/Commands Used
- `ls` — list directory contents
- `mkdir` — create a directory
- `cd ..` — move up one directory level
- `grep` — search text inside a file for a matching string
